## 关于

HonhuCraft（异界之旅）是一个基于 Minecraft Forge 1.20.1 的冒险整合包项目。

## 下载

前往 [Releases](https://github.com/Yuzcen/HonhuCraft/releases) 页面下载最新版本的整合包。

支持两种格式：
- **Modrinth (.mrpack)** — 推荐使用 [Modrinth App](https://modrinth.com/app) 导入
- **CurseForge (.zip)** — 可通过 CurseForge 客户端导入
